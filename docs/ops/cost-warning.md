# ⚠️ 비용 주의사항

## Runpod (GPU) — 유일한 의미 있는 비용

| 상황 | 비용 | 설명 |
|------|------|------|
| Endpoint 삭제 상태 | **$0** | 안전 |
| Endpoint 존재 (workersStandby=1) | **~$11/일** | 항상 1대 유지 |
| 이미지 1장 처리 | **$0.00004** | 사실상 무료 |

### 규칙
1. **테스트 끝나면 endpoint 삭제** — `mcp__runpod__delete-endpoint`
2. **endpoint가 있는지 확인** — `mcp__runpod__list-endpoints` → `[]`이면 OK
3. **밤새 켜두지 말 것** — 8시간 = ~$3.68
