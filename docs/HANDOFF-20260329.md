### 3. E2E 파이프라인 전 구간 테스트 통과
```
Flutter → POST /auth/anon → JWT                          ✅
Flutter → POST /jobs → presigned URLs                    ✅
Flutter → R2 PUT (이미지 업로드)                          ✅
Flutter → POST /jobs/{id}/confirm-upload                  ✅
Flutter → POST /jobs/{id}/execute → Queue push            ✅
Queue → Runpod GPU Worker (SAM3)                          ✅
GPU → R2 다운로드 → SAM3 segment → recolor → R2 업로드   ✅
GPU → POST /jobs/{id}/callback → DO 상태 갱신             ✅
Flutter → GET /jobs/{id} → status=done + download_urls    ✅
```
